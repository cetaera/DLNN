# Jacobi Eigen

Небольшой Python-пакет для спектрального разложения вещественных
симметричных матриц методом Якоби.

## Установка

Требуется Python 3.9 или новее.

```bash
python3 -m pip install .
```

## Быстрый запуск

Из корня проекта пример запускается командой:

```bash
PYTHONPATH=src python3 examples/basic_usage.py
```

Скрипт выводит найденные собственные числа, собственные векторы и число
вращений.

## Пример использования

```python
from jacobi_eigen import jacobi_eigendecomposition

matrix = [
    [4.0, 1.0, -2.0],
    [1.0, 2.0, 0.0],
    [-2.0, 0.0, 3.0],
]

result = jacobi_eigendecomposition(matrix)

print(result.eigenvalues)
print(result.eigenvectors)
print(result.iterations)
```

Собственный вектор с номером `j` находится в столбце `j`:

```python
j = 0
eigenvector = tuple(row[j] for row in result.eigenvectors)
eigenvalue = result.eigenvalues[j]
```

Пары отсортированы по возрастанию собственных чисел. Знак собственного
вектора фиксируется для воспроизводимости: его наибольшая по модулю компонента
неотрицательна.

## Публичный интерфейс

Функция и классы ошибок импортируются непосредственно из `jacobi_eigen`.

```python
jacobi_eigendecomposition(
    matrix,
    tolerance=1e-12,
    max_iterations=None,
    symmetry_tolerance=1e-12,
) -> JacobiResult
```

`JacobiResult` содержит три неизменяемых поля:

- `eigenvalues` - кортеж собственных чисел;
- `eigenvectors` - матрица собственных векторов, записанная по строкам;
- `iterations` - число выполненных вращений.

Исходная матрица копируется. Функция не меняет ни внешний список, ни его
строки.

## Контракт

Контракт описывает допустимые входные данные, гарантии результата и ошибки,
которые может вернуть функция. Проверка входной части контракта выполняется во
время работы программы.

### Входные данные

- `matrix` - непустая квадратная матрица;
- каждый элемент преобразуется в конечный `float`, но логические значения,
  строки и комплексные числа не принимаются;
- матрица должна быть симметричной с учётом `symmetry_tolerance`;
- `tolerance` - положительное конечное число;
- `symmetry_tolerance` - неотрицательное конечное число;
- `max_iterations` - положительное целое число или `None`.

Проверка симметрии для пары элементов `a` и `b` имеет вид

```text
abs(a - b) <= symmetry_tolerance * max(1, abs(a), abs(b)).
```

Если различие укладывается в допуск, рабочая копия получает среднее значение
пары. Это исключает искусственную асимметрию из-за округления входных данных.

### Результат

Для результата `(L, V)` выполняются свойства спектрального разложения:

```text
A @ V[:, j] ~= L[j] * V[:, j]
V.T @ V ~= I
A ~= V @ diag(L) @ V.T
```

Знак `~=` означает равенство в пределах ошибок вычислений с плавающей точкой.
Итерации заканчиваются, когда

```text
sum(A[p][q] ** 2 for p != q) <= tolerance.
```

Число вращений никогда не превышает `max_iterations`. Если предел не указан,
используется `100 * n * n`, где `n` - порядок матрицы. Поэтому функция не может
бесконечно продолжать итерации.

Для кратных собственных чисел конкретные собственные векторы не уникальны:
результатом может быть любой ортонормированный базис соответствующего
собственного подпространства.

### Ошибки

Все предусмотренные ошибки наследуются от `JacobiError`:

| Исключение | Причина |
| --- | --- |
| `InvalidMatrixError` | неверная форма, нечисловой элемент, `NaN`, бесконечность или нарушение симметрии |
| `InvalidToleranceError` | неверный допуск или предел итераций |
| `ConvergenceError` | точность не достигнута за разрешённое число вращений |
| `NumericalError` | промежуточный или конечный результат нельзя представить конечными `float` |

Можно перехватить конкретную причину либо общий `JacobiError`.

## Как работает метод

На каждом шаге выбирается очередной элемент над главной диагональю. Плоское
вращение в соответствующих двух координатах зануляет этот элемент, сохраняя
симметрию матрицы. Те же вращения накапливаются в единичной матрице; её столбцы
становятся собственными векторами.

Пары индексов обходятся циклически. Перед вычислениями матрица делится на
максимальный модуль своего элемента. Такое масштабирование не меняет
собственные векторы и снижает риск переполнения. Тангенс угла считается в
устойчивой форме, без потенциально большого отношения диагональной разности к
зануляемому элементу.

Один полный проход требует `O(n^3)` операций, рабочая память - `O(n^2)`.
