# Самовнимание и производные softmax

## Число параметров

Вход блока самовнимания представлен матрицей `X` размера `D x N`. Каждый ее столбец является входным вектором длины `D`. Значения, ключи и запросы вычисляются тремя аффинными преобразованиями:

```text
V = beta_v * 1^T + Omega_v * X,
K = beta_k * 1^T + Omega_k * X,
Q = beta_q * 1^T + Omega_q * X.
```

Каждая матрица `Omega` имеет размер `D x D`, а каждый вектор `beta` имеет длину `D`. Поэтому используются:

```text
веса:      3*D^2,
смещения:  3*D,
всего:     3*D^2 + 3*D = 3*D*(D + 1).
```

Матрица внимания имеет размер `N x N` и содержит `N^2` коэффициентов. Эти коэффициенты зависят от входа и вычисляются заново для каждой последовательности. Они не являются независимыми обучаемыми параметрами.

Пусть скрытый слой двуслойного полносвязного перцептрона содержит `H` нейронов. Размер его входа и выхода равен `D*N`. Число параметров равно:

```text
H*D*N + H + D*N*H + D*N = 2*H*D*N + H + D*N.
```

Если ширина скрытого слоя совпадает с размером входа и выхода, то есть `H = D*N`, получаем:

```text
2*(D*N)^2 + 2*D*N = 2*D^2*N^2 + 2*D*N.
```

Таким образом, число обучаемых параметров самовнимания не зависит от длины последовательности `N`, а для полносвязного перцептрона выбранной ширины растет как `N^2`.

## Эквивариантность к перестановке

Обозначим через `1^T` строку из `N` единиц. Для матрицы перестановки `P` выполняются равенства:

```text
P*P^T = P^T*P = I,
1^T*P = 1^T.
```

Для любого из трех аффинных преобразований `F` значений, ключей или запросов:

```text
F(X*P) = beta*1^T + Omega*X*P
       = (beta*1^T + Omega*X)*P
       = F(X)*P.
```

Следовательно:

```text
V(X*P) = V(X)*P,
K(X*P) = K(X)*P,
Q(X*P) = Q(X)*P.
```

Обозначим матрицу скалярных произведений через `Z(X) = K(X)^T*Q(X)`. Тогда:

```text
Z(X*P) = (K(X)*P)^T*(Q(X)*P)
       = P^T*Z(X)*P.
```

Функция softmax применяется отдельно к каждому столбцу: индекс строки соответствует ключу, а индекс столбца соответствует запросу. Перестановка строк меняет порядок слагаемых, но не меняет их сумму. Перестановка столбцов только меняет порядок независимо нормируемых столбцов. Поэтому:

```text
softmax(P^T*Z*P) = P^T*softmax(Z)*P.
```

Используя определение `Sa(X) = V(X)*softmax(K(X)^T*Q(X))`, получаем:

```text
Sa(X*P) = V(X)*P*P^T*softmax(Z(X))*P
        = V(X)*softmax(Z(X))*P
        = Sa(X)*P.
```

Операция самовнимания эквивариантна относительно перестановки входных столбцов.

## Производные softmax

Для

```text
y_i = exp(z_i) / sum(exp(z_k))
```

производная имеет вид:

```text
d(y_i)/d(z_j) = y_i*(delta_ij - y_j),
```

где `delta_ij` равна единице при `i = j` и нулю в остальных случаях.

При `z = (-3, 1, 100, 5, -1)` значения softmax равны:

| Компонента | Значение |
| ---: | ---: |
| `y_1` | `1.8521167695179755e-45` |
| `y_2` | `1.0112214926104485e-43` |
| `y_3` | `1 - 5.6377419377708341e-42` |
| `y_4` | `5.5210822770285327e-42` |
| `y_5` | `1.3685394711738530e-44` |

Матрица Якоби. Строка соответствует индексу `i`, столбец соответствует индексу `j`:

|  | `z_1` | `z_2` | `z_3` | `z_4` | `z_5` |
| --- | ---: | ---: | ---: | ---: | ---: |
| `y_1` | `1.8521167695179755e-45` | `-1.8729002841608092e-88` | `-1.8521167695179755e-45` | `-1.0225689071173034e-86` | `-2.5346949043083551e-89` |
| `y_2` | `-1.8729002841608092e-88` | `1.0112214926104485e-43` | `-1.0112214926104485e-43` | `-5.5830370610018868e-85` | `-1.3838965267367375e-87` |
| `y_3` | `-1.8521167695179755e-45` | `-1.0112214926104485e-43` | `5.6377419377708341e-42` | `-5.5210822770285327e-42` | `-1.3685394711738530e-44` |
| `y_4` | `-1.0225689071173034e-86` | `-5.5830370610018868e-85` | `-5.5210822770285327e-42` | `5.5210822770285327e-42` | `-7.5558190197119604e-86` |
| `y_5` | `-2.5346949043083551e-89` | `-1.3838965267367375e-87` | `-1.3685394711738530e-44` | `-7.5558190197119604e-86` | `1.3685394711738530e-44` |

Третья компонента почти полностью определяет результат, поскольку `z_3 = 100` намного больше остальных значений. Все элементы матрицы Якоби по модулю не превышают примерно `5.64e-42`. Softmax находится в области насыщения, поэтому небольшое изменение любого входа почти не изменяет выход и градиент практически исчезает.

Диагональные производные положительны, внедиагональные отрицательны. Сумма элементов каждой строки и каждого столбца равна нулю с учетом точности вычислений. Это следует из нормировки вероятностей и из того, что прибавление одной константы ко всем компонентам `z` не меняет softmax.

Программа использует арифметику `Decimal` с точностью 100 знаков и вычисляет экспоненты после вычитания максимального значения. Такой расчет сохраняет малые производные и не допускает переполнения при вычислении `exp(100)`.
