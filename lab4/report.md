# Двухслойный перцептрон для расчета липофильности

## Данные и модель

Выборка содержит 82 вещества, значение `logP` и 24 молекулярных дескриптора. Для расчета используется двухслойный перцептрон с одним скрытым слоем:

```text
y* = b2 + w2^T relu(W1*x* + b1).
```

Здесь `x*` и `y*` - стандартизованные значения признаков и отклика. Перед обучением из каждой переменной вычитается среднее, затем результат делится на стандартное отклонение. После расчета прогноз возвращается к исходной шкале `logP`:

```text
x* = (x - mean(x)) / std(x)
logP = mean(logP) + std(logP)*y*.
```

Нормировка нужна из-за большой разницы в масштабах дескрипторов. Например, счетчики функциональных групп обычно принимают небольшие целые значения, а `PSA` и `MR` измеряются десятками и сотнями.

Для скрытого слоя из `m` нейронов модель содержит `26m + 1` параметров: матрицу `W1` размера `m x 24`, вектор `b1` длины `m`, вектор `w2` длины `m` и скаляр `b2`. Рассмотрены значения `m = 2, 4, 8, 16, 32`.

## Градиентный спуск

Минимизируется половина средней квадратичной ошибки в стандартизованной шкале:

```text
J = (1 / (2n))*sum((y* - y_pred*)^2).
```

Градиенты вычисляются вручную по формулам обратного прохода через ReLU. Производная ReLU в нуле принята равной единице. Используется полный градиент по всем 82 наблюдениям. Начальные веса генерируются по схеме Хе с фиксированным начальным состоянием генератора `42`, смещения равны нулю.

Во всех моделях зафиксированы:

- начальная скорость обучения `epsilon = 0.03`;
- точность `delta = 0.005`;
- предельное число итераций `50000`.

Алгоритм считается сошедшимся, когда евклидова норма полного градиента становится меньше `delta`.

Ошибка изменяется немонотонно с размером скрытого слоя. При 82 наблюдениях результат определяется не только числом параметров, но и переобучением, начальным приближением и попаданием градиентного спуска в разные области невыпуклой функции потерь. Разброс между тремя запусками особенно велик для ручных моделей с 16 и 32 нейронами и библиотечной модели с 4 нейронами. Поэтому отдельный запуск не дает устойчивого ранжирования архитектур. Этот вывод основан на самих различиях между запусками, а приведенное стандартное отклонение служит лишь их компактным описанием.

Для библиотечной модели с 4 нейронами OOF RMSE при seed `41`, `42` и `43` равны `1.614967`, `3.528563` и `2.887241`. Худший результат существенно превышает как линейный ориентир `1.230472`, так и результат этой же архитектуры при seed `41`. В каждом фолде такая сеть оценивает 105 параметров примерно по 65 наблюдениям, причем `MLPRegressor` используется без регуляризации (`alpha = 0`) и со строгой точностью оптимизации (`tol = 1e-6`). Такое сочетание согласуется с глубокой подгонкой обучающих частей и неустойчивой экстраполяцией на контрольные наблюдения. Это правдоподобное объяснение выброса, но не доказательство его единственной причины: для разделения влияния регуляризации, критерия остановки и начальных весов нужны отдельные контролируемые запуски.

В трех из пяти обучающих частей встречаются регрессоры с нулевой дисперсией, максимум два одновременно. Для вычислений их масштаб принят равным единице. Такие столбцы не несут информации внутри соответствующей обучающей части. Если ненулевое значение появляется в контрольной части, прогноз для него является экстраполяцией. Это связано с редкостью отдельных функциональных групп и дополнительно снижает устойчивость оценки.

Линейная регрессия на всей выборке имеет `RMSE = 0.640930` и `R^2 = 0.837989`. Обучающие показатели ручных моделей приведены выше в таблицах для постоянной и убывающей скорости.

Итерации L-BFGS нельзя напрямую приравнивать к шагам обычного градиентного спуска. Решатель использует оценки кривизны функции потерь и выбирает направление и длину шага иначе.

Для широких слоев L-BFGS достигает значительно меньшей обучающей ошибки, чем ручной градиентный спуск. Например, при 32 нейронах значения RMSE равны `0.123742` и `0.216618`. В перекрестной проверке соотношение меняется: средние RMSE равны `1.672546` и `1.526555`. Это согласуется с гипотезой, что остановка ручного алгоритма при норме градиента меньше `0.005` ограничивает глубину подгонки и может действовать как неявная регуляризация. Гипотеза не проверена отдельным опытом. Для ее проверки нужно уменьшить `delta` при неизменных разбиениях и начальных весах и проследить одновременно за обучающей и вневыборочной ошибкой. Кроме критерия остановки, результаты могут различаться из-за самих алгоритмов оптимизации и их траекторий.

На обучающей выборке нейросетевые реализации имеют меньшую ошибку, чем линейная регрессия. Перекрестная проверка меняет вывод: линейная модель получает `RMSE = 1.230472`, что меньше среднего результата любой нейросетевой архитектуры. Следовательно, разрыв обучающих ошибок не доказывает наличие полезной нелинейной зависимости. Он в значительной степени связан с подгонкой более сложных моделей.

Модель с 4 нейронами содержит 105 параметров при 82 наблюдениях, а модель с 32 нейронами - 833 параметра. Высокий обучающий `R^2` при заметно худших вневыборочных результатах указывает на переобучение. По имеющейся выборке нет оснований считать двухслойный перцептрон более надежным для прогноза `logP`, чем линейную модель.

## Локальная чувствительность регрессоров

Перестановка отдельных столбцов не используется, поскольку при сильной корреляции дескрипторов она создает сочетания, отсутствующие в исходной выборке. Вместо нее для ручной модели с 4 нейронами вычислена средняя абсолютная производная прогноза по каждому стандартизованному входу. Этот размер слоя имеет наименьшую среднюю вневыборочную ошибку среди ручных моделей в выбранном разбиении.

```text
s_j = mean(abs(d(logP_pred) / d(x_j*))).
```

Величина показывает средний модуль локальной производной в точках реальных наблюдений. Одна единица стандартизованного входа соответствует одному стандартному отклонению дескриптора. Это локальная скорость изменения, а не прогноз конечного изменения после сдвига признака на целую единицу. Для оценки направления связи дополнительно рассчитана средняя знаковая производная

```text
d_j = mean(d(logP_pred) / d(x_j*)).
```

Положительное значение `d_j` означает, что в окрестности наблюдаемых веществ увеличение дескриптора в среднем связано с ростом прогноза `logP`, отрицательное - со снижением. Из-за нелинейности модели и корреляций между признаками это не следует интерпретировать как независимый причинный эффект.

Результат частично согласуется с физическими представлениями о липофильности. Для `PSA` получена сильная отрицательная связь: увеличение площади полярной поверхности усиливает взаимодействие с водой и обычно уменьшает `logP`. Отрицательная средняя производная `HBA1` также согласуется с тем, что центры образования водородных связей повышают сродство к полярной фазе. Положительная производная `MR` соответствует ожидаемой связи липофильности с размером и поляризуемостью молекулы. В линейной модели положительный стандартизованный коэффициент числа атомов углерода `C` также соответствует усилению гидрофобной части молекулы.

Для `HBA2` получено положительное направление, которое не согласуется с простой интерпретацией акцепторов как фактора гидрофильности. Это не следует считать самостоятельным физическим эффектом: `HBA2` почти линейно связан с `PSA`, `HBA1` и другими размерными дескрипторами, поэтому модель может распределять их совместное влияние между коэффициентами с разными знаками. У `RNH2` большой средний модуль сочетается с близкой к нулю средней знаковой производной, то есть направление локального влияния меняется между веществами. Следовательно, ранжирование надежнее использовать для описания чувствительности конкретной модели, чем для причинного вывода о химической структуре.

Программа отдельно рассчитывает стандартизованные коэффициенты линейной модели. Пять наибольших значений по модулю:

| Регрессор | Стандартизованный коэффициент |
| --- | ---: |
| C | 2.262405 |
| HBA2 | 2.158611 |
| PSA | -1.741027 |
| HBA1 | -1.071227 |
| MR | -1.006512 |

Четыре признака входят в первую пятерку обеих оценок: `PSA`, `HBA1`, `HBA2` и `MR`. При этом `C`, имеющий наибольший по модулю стандартизованный коэффициент линейной модели, не входит в первую пятерку чувствительности перцептрона: его средняя абсолютная производная равна `0.955192`. Вместо него появляется `RNH2`. Это показывает, что ранжирование зависит от формы модели и не переносится напрямую с линейной регрессии на перцептрон.

Стандартные отклонения и различия между средними и медианами показывают, что производные заметно меняются от вещества к веществу. ReLU-модель является кусочно-линейной, поэтому ее производная определяется активным набором скрытых нейронов в конкретной точке. Для небольшой сети усредненный модуль производной в большей степени характеризует жесткость конкретной кусочно-линейной аппроксимации, чем физический вклад дескриптора. Средний модуль сам по себе не определяет направление связи; средняя знаковая производная описывает лишь локальное направление модели и не является причинным эффектом. При сильной корреляции дескрипторов влияние может перераспределяться между ними. Результат также зависит от архитектуры и начальных весов, поэтому его следует рассматривать только как характеристику конкретной обученной модели.

Знак линейного коэффициента `HBA2` положительный (`2.158611`), тогда как коэффициенты `HBA1` и `PSA` отрицательные. Эти знаки нельзя интерпретировать как независимые физические эффекты. Корреляции `HBA2` с `PSA`, `HBA1`, `MR`, `C` и `RINGS` равны соответственно `0.9781`, `0.9747`, `0.8847`, `0.8124` и `0.8013`. При такой мультиколлинеарности коэффициент показывает частный результат совместной подгонки связанных признаков.

## Веса и воспроизводимость

Файл `weights.json` содержит параметры десяти ручных моделей, обученных на полной выборке: пяти моделей с постоянным шагом и пяти моделей с убывающим шагом. Модели перекрестной проверки и библиотечные модели в этот файл не сохраняются. Для каждого сохраненного варианта записаны `W1`, `b1`, `w2` и `b2`, а также средние и стандартные отклонения, использованные для нормировки. Формула в метаданных явно использует `x_standardized`; дополнительно сохранены правило нормировки, предел итераций, seed и параметры убывания шага. Файл создается заново при каждом запуске программы.

Запуск из папки `lab4`:

```bash
python3 -m pip install -r requirements.txt
python3 main.py
```
